Scorpion Backup

Scorpion Backup is a personal, non-commercial backup setup for one owner's Flashforge AD5X 3D printer. It uses rclone on the owner's computer to store printer configuration backups and recovery files in the owner's Google Drive account.

The intended setup encrypts backup contents and filenames locally with rclone crypt before uploading them. The Google Drive connection requests the drive.file permission, which is limited to files the application creates or is explicitly allowed to access.

This is a personal tool, not a public backup service. This website does not collect files, sign-in information, or printer data. Backups are not hosted on this website.

Read the Privacy Policy for details about how Google Drive data is handled.
